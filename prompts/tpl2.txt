# Task

Generate Personal Enhancement records for an existing English Knowledge Point.

The generated records must supplement the existing knowledge instead of modifying it.

{{Knowledge Point}}

Optional Parameters

Audience

{{Audience}}

Language

{{Audience}}


---

# Goal

Assume you are an experienced English teacher helping a learner deepen their understanding of an existing Knowledge Point.

Generate ONE Personal Enhancement record.

The record should contain multiple content items in the "content" array.

Each content item should provide a different learning perspective while targeting the same Target Type.

The generated content should make the knowledge easier to:

- understand
- remember
- distinguish
- apply

Do not simply rewrite the existing definition.

---

# Requirements

1. Read and understand the existing Knowledge Point before generating any content.

2. Follow the provided schema exactly.

3. Do NOT modify the original Knowledge Point.

4. Every generated record must reference the original Knowledge Point.

5. Generate ONE Personal Enhancement object.

  Populate its "content" array with one or more content items.

  Every content item must match the specified Target Type.

  Do not create multiple Personal Enhancement objects unless explicitly requested.

6. The generated content should match the specified CEFR difficulty.

7. Avoid repeating information already contained in the Base Knowledge.

8. Every enhancement should provide a different learning perspective.

9. Prefer practical learning value over completeness.

10. If no meaningful enhancement can be generated, return an empty array.

11.Each content item should provide unique learning value. Do not generate duplicate or overlapping content items.

---

# Target Type Guidelines

If Target Type = DEFINITION

Generate:

- easier explanations
- alternative explanations
- learner-friendly explanations

---

If Target Type = EXAMPLE

Generate:

- more practical examples
- real-world examples
- frequently used examples

---

If Target Type = COMPARISON

Generate comparisons with the specified Compare With concepts.

Include:

- similarities

- differences

- how to choose correctly

- common learner confusion

---

If Target Type = ASSOCIATION

Generate:

- related grammar

- related vocabulary

- collocations

- word families

- useful connections

---

If Target Type = SCENARIO

Generate practical situations where this knowledge is naturally used.

---

If Target Type = CONFUSION

Generate common learner misunderstandings and explain how to distinguish them.

---

If Target Type = MNEMONIC

Generate memory methods that are logical and easy to remember.

Avoid fake etymology.

---

If Target Type = EXTENSION

Recommend what learners should study next.

Only recommend closely related knowledge.

---

# Quality Checklist

Before generating each record, verify that it satisfies ALL of the following:

✓ adds new learning value

✓ is not already present in the Base Knowledge

✓ is useful for learners

✓ matches the requested Target Type

✓ follows the schema

If any condition is not satisfied, do not generate that record.

---

# Output

Write the generated records directly into:

personal\Enhancement

Requirements

- Follow schema-personal-enhancement.json.
- Do not print the JSON to the console.
- Create or update files as appropriate.
- Avoid duplicate enhancements.
- Preserve existing files unless an update is necessary.

When finished, print only a concise summary of created and updated files.
